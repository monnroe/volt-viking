# Volt Viking

Personal technical portfolio for electrical engineering, telecom, EKOM and offshore projects.

## Deployment

This repository is intended to host the Volt Viking static website with GitHub Pages. Upload `index.html`, `styles.css`, `theme.css`, `refined.css`, `script.js`, and the `assets/` directory from the approved cinematic redesign package, maintaining relative paths.

**Privacy:** Do not upload the `bevis/` folder of personal certificates without reviewing each document for personal information.

When the site files are ready, make the repository public if appropriate and enable GitHub Pages from Settings → Pages → Deploy from a branch (`main`, `/root`).
